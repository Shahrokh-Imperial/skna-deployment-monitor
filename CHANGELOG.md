# Changelog

## 1.0.0 — first public release

- Default threshold baseline changed to up to 60 s immediately before event onset.
- Default replay persistence changed to two updates.
- Removed frozen manuscript thresholds and real Pig 667 examples.
- Added synthetic examples, user documentation, tests, privacy guidance, and consistent version metadata.
- Retained cached parsing and 2-GB Streamlit upload configuration for large recordings.
